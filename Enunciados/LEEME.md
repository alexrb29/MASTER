# Inicio rápido

1. Lee ENUNCIADO-CAMPUS.md y DICCIONARIO-DATOS.md.
2. Copia datos y scripts a tu proyecto de dashboard.
3. Ejecuta `node scripts/procesar.mjs`.
4. Completa los TODO para generar resumen y calidad.
5. Conecta el resumen a la interfaz y documenta tus comprobaciones.

Los archivos son sintéticos. El script inicial está probado para leerlos, pero las funciones pendientes de la actividad todavía no están implementadas.
